# Sara — A Little Universe ♡

A personalized interactive Arabic birthday website for Sara (21 November).

- Entry point: `index.html`
- Hosting: GitHub Pages (static)
- Contains personal birthday messages and original music; please be mindful of privacy before making this repository public.

This website works without a backend. To publish on GitHub Pages, configure **Settings → Pages** to deploy from the `main` branch root, or select GitHub Actions after adding a workflow.
